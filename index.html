Step 01 of 03

Set up your
home on the internet.

GitHub will host your site for free and give it a real URL — your name will literally become your-name.github.io. No payment, no domain registration, no server admin.

Step 01 · 01 6 cards in this step

Create a free
GitHub account.

You'll spend the rest of this walkthrough inside GitHub, so take a moment to set things up properly.

Heads up: a GitHub account also unlocks Codespaces (your in-browser code editor) and GitHub Pages (your future website). One signup, three tools.
Open github.com/signup ↗
Step 01 · 02 6 cards in this step

Your username
becomes your URL.

Once you pick a username, it locks in as your-username.github.io. That's the only place it appears in your URL, so it's worth a moment of thought.

Pick a username that's…

  • Short and typeable — you'll say it on calls
  • Professional — same one across GitHub & LinkedIn feels clean
  • Pronounceable — recruiters will try
Step 01 · 03 6 cards in this step

Make a new
repository.

A repository is just a folder that holds your website's files. Think of it as the project folder for your site.

  1. Click the + in the top-right of any GitHub page
  2. Choose New repository
  3. Set visibility to Public (free hosting only works for public repos)
Don't add a README, .gitignore, or license yet — keep it bare and we control what goes inside.
Step 01 · 04 6 cards in this step

Name it
[username].github.io

The repo name is special. The pattern your-name.github.io tells GitHub “this folder is a website” — it switches from a normal repo to a live page automatically.

! The exact pattern matters. If your username is chloemarketing, your repo name must be chloemarketing.github.io — not chloemarketing.com or chloe-website.
Step 01 · 05 6 cards in this step

Open it in
Codespaces.

Codespaces is a code editor that runs in your browser — like Google Docs, but for code. Zero installs, zero setup, works on any laptop.

  1. Inside the repo, click the green Code button
  2. Open the Codespaces tab
  3. Hit Create codespace on main
Free tier: you get 60 hours/month on a 2‑core machine. More than enough for everything we'll do here.
Step 01 · 06 6 cards in this step · last one!

Done with step 1.

Switch back to your GitHub repo tab and leave it open in the background. You'll upload the finished files here in step 3.

Step 02 of 03

Now have an AI
build it for you.

The hard part of a website is the design and the decisions — typography, layout, what to show. The AI does that for you in seconds. You stay in the loop as a director: you describe, it produces, you steer.

Step 02 · 01 2 cards in this step

Sign in to your
AI assistant.

Pick whichever assistant you have access to. All of them can write a complete website from a prompt.

WorkBuddy easiest

This app — no setup, no VPN, free during the trial.

Codex

Claude Code

Paid Claude subscription + VPN. Powerful, terminal-style workflow.

Direct the AI,
iterate, ship.

A first prompt should describe the kind of site you want, not every detail. The AI will give you something — tell it what to change. Repeat until you love it.

Step 03 of 03

Push it to
the open internet.

Last 60 seconds. GitHub Pages takes the files you upload and serves them to the world. No server to babysit — your site stays up as long as the repo exists.

Step 03 · 01 5 cards in this step

Confirm Pages
is on main / root.

Back on your repo tab, open Settings → Pages. You should see a “Build and deployment” section with the source already set — but let's double-check.

✓ Source: Deploy from a branch
✓ Branch: main
✓ Folder: / (root)
If Pages isn't enabled, GitHub will probably tell you here. That's fine — we'll fix it on the next card.
Step 03 · 02 5 cards in this step

Find the
Upload files button.

On the main repo page (the Code tab, not Settings), you should see an Add file ▾ dropdown. Click it and choose Upload files.

i If you only see a single button that says Upload files, click that. Either works.
Step 03 · 03 5 cards in this step

Drop the files,
write a message, commit.

Drag index.html in. If your AI also gave you CSS, JS, or image files, drag them too — all at once, in one batch.

A typical upload looks like:

  • index.html
  • styles.css (optional)
  • app.js (optional)
  • assets/ folder (if you have images)
! If your AI gave you a folder structure, upload the contents of the folder, not the folder itself. The file index.html must sit at the repo root.

Step 03 · 04

Wait about a minute.
Then watch this.

Your future URL

Press the button below to deploy…

Click Deploy to simulate the build. (In real life, GitHub is doing this — you just kicked it off when you committed.)

✓ Step 03 · 05 · you did it

You're live
on the open internet.

What now?

A
Share the URL.

LinkedIn bio, email signature, business cards. Once it's out there, it's out there.

B
Custom domain.

Buy a your-name.com (~$10/yr) and point it at GitHub Pages in DNS settings.

C
Update it any time.

Edit a file → commit → GitHub rebuilds in < 30 seconds. That's the whole workflow forever.

D
Track visits.

Drop in a privacy-friendly analytics tool (Plausible, Umami) to see who's reading.
